## 1. Pourquoi Vim est différent

Contrairement à nano, Vim est un éditeur **modal** : les touches n'ont pas toujours le même effet, cela dépend du mode dans lequel vous êtes. C'est déroutant au début, mais c'est précisément ce qui rend Vim redoutablement efficace une fois maîtrisé : en mode Normal, chaque touche du clavier devient une commande d'édition, sans jamais quitter le clavier alphanumérique pour les flèches ou la souris.

|  | **nano** | **Vim** |
| --- | --- | --- |
| Philosophie | Ce que vous tapez apparaît directement | Les touches sont des commandes selon le mode |
| Courbe d'apprentissage | Immédiate | Plus raide, mais très rentable sur la durée |
| Efficacité à terme | Correcte | Très élevée (édition par blocs, répétition, macros) |
| Présence par défaut | La plupart des distributions | `vi` est présent sur quasiment tous les Unix/Linux |

```bash
# Debian / Ubuntu
sudo apt update && sudo apt install vim

# macOS (vim est préinstallé, souvent une vieille version)

```

> Note : `vi` (sans le "m") est l'ancêtre historique, presque toujours préinstallé mais plus limité. `vim` ("Vi IMproved") est la version moderne que ce cours utilise.

## 3. Les modes de Vim — le concept central

```mermaid
stateDiagram-v2
    [*] --> Normal
    Normal --> Insertion: i, a, o, O...
    Insertion --> Normal: Échap
    Normal --> Visuel: v, V, Ctrl+V
    Visuel --> Normal: Échap
    Normal --> Commande: :
    Commande --> Normal: Entrée
    Normal --> Remplacement: R
    Remplacement --> Normal: Échap
```

| Mode | Rôle | Comment y entrer |
| --- | --- | --- |
| **Normal** | Mode par défaut : naviguer et exécuter des commandes (le "chez-soi" de Vim) | `Échap` depuis n'importe quel autre mode |
| **Insertion** | Taper du texte, comme dans un éditeur classique | `i`, `a`, `o`, `O` depuis le mode Normal |
| **Visuel** | Sélectionner du texte pour agir dessus | `v`, `V`, `Ctrl+V` depuis le mode Normal |
| **Commande** | Taper des commandes Ex (`:w`, `:q`, `:%s/...`) | `:` depuis le mode Normal |
| **Remplacement** | Écraser le texte existant caractère par caractère | `R` depuis le mode Normal |

**Règle d'or** : en cas de doute sur le mode dans lequel vous êtes, appuyez sur `Échap` — cela vous ramène toujours en mode Normal, votre position de repli sûre.

## 4. Premiers pas

```bash
vim fichier.txt        # ouvrir (ou créer) un fichier
```

### Entrer en mode Insertion

| Commande | Effet |
| --- | --- |
| `i` | Insérer **avant** le curseur |
| `a` | Insérer **après** le curseur |
| `o` | Ouvrir une **nouvelle ligne en dessous** et insérer |
| `O` | Ouvrir une **nouvelle ligne au-dessus** et insérer |
| `Échap` | Revenir en mode Normal |

### Sauvegarder et quitter (en mode Normal, via `:`)

| Commande | Effet |
| --- | --- |
| `:w` | Sauvegarder (write) |
| `:q` | Quitter (refuse s'il y a des modifications non sauvegardées) |
| `:wq` ou `:x` | Sauvegarder puis quitter |
| `:q!` | Quitter **sans sauvegarder**, en forçant |
| `ZZ` | Raccourci en mode Normal pour sauvegarder et quitter |

## 5. Navigation de base (en mode Normal)

### Déplacement caractère par caractère

```
      k
      ↑
  h ← · → l
      ↓
      j
```

| Touche | Effet |
| --- | --- |
| `h` | Gauche |
| `j` | Bas |
| `k` | Haut |
| `l` | Droite |

### Déplacement par mots et lignes

| Touche | Effet |
| --- | --- |
| `w` | Début du mot suivant |
| `b` | Début du mot précédent |
| `e` | Fin du mot courant/suivant |
| `0` | Début absolu de la ligne |
| `^` | Premier caractère non-blanc de la ligne |
| `$` | Fin de la ligne |
| `gg` | Début du fichier |
| `G` | Fin du fichier |
| `:42` ou `42G` | Aller à la ligne 42 |
| `Ctrl+F` / `Ctrl+B` | Page suivante / précédente |
| `Ctrl+D` / `Ctrl+U` | Demi-page bas / haut |

**Astuce fondamentale** : préfixer une commande de navigation par un nombre la répète. `5j` descend de 5 lignes, `3w` avance de 3 mots.

## 6. Édition de base

| Commande | Effet |
| --- | --- |
| `x` | Supprimer le caractère sous le curseur |
| `dd` | Supprimer (couper) la ligne courante |
| `dw` | Supprimer jusqu'à la fin du mot |
| `yy` | Copier (yank) la ligne courante |
| `p` | Coller **après** le curseur/la ligne |
| `P` | Coller **avant** le curseur/la ligne |
| `u` | Annuler (undo) |
| `Ctrl+R` | Rétablir (redo) |
| `.` | **Répéter la dernière modification** — l'une des commandes les plus puissantes de Vim |

### Le principe verbe + objet

Beaucoup de commandes Vim suivent le schéma **verbe + mouvement** :

```
d  +  w   →  dw   (delete + word     = supprimer un mot)
d  +  $   →  d$   (delete + end line = supprimer jusqu'à la fin de la ligne)
y  +  y   →  yy   (yank + yank(ligne)= copier la ligne)
c  +  w   →  cw   (change + word     = remplacer un mot)
```

Comprendre ce principe est la clé pour ne plus jamais avoir à mémoriser des centaines de raccourcis isolés — vous les **composez**.

## 7. Recherche de base

| Commande | Effet |
| --- | --- |
| `/motif` | Rechercher vers l'avant |
| `?motif` | Rechercher vers l'arrière |
| `n` | Occurrence suivante (dans le sens de la recherche) |
| `N` | Occurrence précédente |
| `*` | Rechercher le mot sous le curseur, vers l'avant |
| `#` | Rechercher le mot sous le curseur, vers l'arrière |

---

## 8. Mode Visuel de base

| Commande | Effet |
| --- | --- |
| `v` | Sélection **caractère par caractère** |
| `V` | Sélection **ligne par ligne** |
| `Ctrl+V` | Sélection **par bloc** (rectangle) |

Une fois la sélection faite avec les touches de navigation, appliquez une action :

```
v  (sélectionner)  →  déplacer le curseur  →  d (supprimer) ou y (copier) ou c (remplacer)
```

## 📖 Glossaire

| Terme | Définition |
| --- | --- |
| **Édition modale** | Un même clavier produit des effets différents selon le mode actif |
| **Yank** | Le terme Vim pour "copier" |
| **Motion** | Une commande de déplacement (`w`, `$`, `gg`...) utilisable seule ou combinée à un verbe |
| **Commande Ex** | Commande tapée après `:` (héritée de l'éditeur historique `ex`) |
| **Buffer** | Le fichier tel qu'il est chargé en mémoire dans Vim |
