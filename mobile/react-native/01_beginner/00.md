# Plan d'apprentissage React Native – Niveau Débutant

## 🎯 Objectif
Acquérir les compétences nécessaires pour créer des applications mobiles **iOS et Android** avec **React Native**, depuis l'installation de l'environnement jusqu'au déploiement d'une première application simple.

---

## 📅 Durée conseillée
**4 à 6 semaines** (environ 10‑15 h par semaine) – ajustable selon votre rythme.

---

## 📚 Structure du plan
| Semaine | Thème | Sous‑thèmes | Ressources clés | Livrable pratique |
|---------|-------|-------------|-----------------|-------------------|
| 1 | **Installation & premier projet** | - Node.js & npm / Yarn<br>- Expo CLI vs React Native CLI<br>- Création d’un projet Expo<br>- Structure d’un projet RN | • Documentation officielle (Expo) <br>• Tutoriel "Getting Started" <br>• Vidéo courte YouTube | App "Hello World" affichant texte + image | 
| 2 | **Fondamentaux du UI** | - Composants de base (`View`, `Text`, `Image`, `ScrollView`)<br>- Styles avec Flexbox<br>- Gestion des dimensions (responsive) | • Docs React Native – Layout<br>• Article Flexbox cheat‑sheet | Page d’accueil avec liste scrollable d’items | 
| 3 | **Navigation** | - React Navigation (stack, tab, drawer)<br>- Passage de paramètres entre écrans<br>- Gestion de l’état de navigation | • React Navigation tutorial<br>• Vidéo "React Navigation 6" | Mini‑application avec deux écrans : liste ↔ détail | 
| 4 | **Gestion d'état** | - `useState`, `useEffect`<br>- Contexte (`Context API`)<br>- Introduction à Redux Toolkit (optionnel) | • Docs React – Hooks<br>• Tutoriel Redux Toolkit (section simple) | Formulaire d’ajout d’item persistant en mémoire | 
| 5 | **Accès aux APIs natives** | - Permissions (camera, localisation)<br>- Utilisation de `fetch` pour API REST<br>- Stockage local (`AsyncStorage`) | • Expo Permissions docs<br>• Exemple d’API météo public | App qui récupère la météo d’une ville et l’affiche |

---

## 🛠️ Outils & Environnement
- **Node.js** (≥ 16) et **npm** (ou **Yarn**)
- **Expo Go** (app mobile) pour tester rapidement
- **VS Code** avec extensions React Native
- **Git** pour le versionnage
- (Optionnel) **Android Studio** & **Xcode** pour builds natifs

---

## 📌 Bonnes pratiques pour débutants
1. **Commencer petit** – chaque nouvelle notion doit être appliquée dans un petit component.
2. **Utiliser le design system** – choisissez une palette de couleurs et respectez le même style.
3. **Documenter** – ajoutez un `README.md` à chaque projet avec les commandes pour lancer et build.
4. **Faire des commits fréquents** – chaque fonctionnalité = un commit clair.
5. **Tester sur les deux plateformes** régulièrement (iOS & Android) pour éviter les surprises.
