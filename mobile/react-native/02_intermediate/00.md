# Plan d'apprentissage React Native – Niveau Intermédiaire

## 🎯 Objectif
Passer du niveau **débutant** à **intermédiaire** en étant capable de :
- Concevoir des applications complexes avec une architecture scalable.
- Utiliser TypeScript, Redux Toolkit, et les API natives de manière fluide.
- Implémenter des animations, de la navigation avancée, du testing automatisé et préparer le déploiement sur les stores.

---

## 📅 Durée conseillée
**6 à 8 semaines** (environ 12‑18 h par semaine). Vous pouvez adapter le rythme selon le temps disponible.

## 🛠️ Outils & Environnement conseillé
- **Node.js** ≥ 18, **npm** ou **Yarn**
- **Expo CLI** (ou React Native CLI si vous devez toucher du code natif)
- **VS Code** avec extensions : ESLint, Prettier, React Native Tools
- **Android Studio** & **Xcode** (pour builds natifs) – optionnel avec Expo EAS
- **Git** + GitHub (ou GitLab) pour le versionnage & CI
- **EAS CLI** (`npm i -g eas-cli`) pour les builds cloud

---

## ✅ Bonnes pratiques pour le niveau intermédiaire
1. **Modulariser dès le départ** – chaque fonctionnalité dans son propre dossier (`features/`, `components/`, `services/`).
2. **Écrire des types** avant le code – le typage évite les bugs difficiles à traquer.
3. **Tests en continu** – chaque nouvelle fonction doit être accompagnée d’un test.
4. **Profiler régulièrement** – utilisez le Profiler de React Native Debugger pour détecter les re‑renders inutiles.
5. **Documenter l’architecture** – créez un README décrivant la structure du store, la navigation et les conventions de code.
